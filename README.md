Pemrograman Visual adalah pemrograman yang dilakukan melalui interaksi  visual, sehingga tidak perlu memahami syntax atau kode terlebih dahulu. Logika Pemrograman Visual direpresentasikan melalui blok, diagram atau elemen grafis yang saling terhubung sesuai dengan alur program. Komponen dan Antarmuka Pemrograman Visual dapat disusun menggunakan mekanisme drag and drop. Perubahan pada rancangan dan struktur program dapat langsung dilihat sehingga memudahkan proses pengembangan.

Adapun tujuan dan manfaat dari pemrograman visual adalah :
1. Mempermudah pemahaman konsep pemrograman
2. Menyajikan alur program secara visual dan terstruktur
3. Mempersiapkan pengguna sebelum memahami sintaks
4. Meminimalisir kesalahan penulisan kode

Tetapi Pemrograman Visual memiliki beberapa batasan yaitu Fleksibilitas nya terbatas, Kurang efisien untuk proyek besar dan terlalu bergantung pada Platform. Platform yang biasa digunakan adalah Scrath, MIT App Inventor, Visual Basic, dan JavaFX.

Untuk memulai, kita diharapkan memahami Visual Basic, karena Visual Basic merupakan bahasa pemrograman dari Microsoft yang menyediakan lingkungan terintegrasi untuk membangun aplikasi dengan pendekatan visual.
